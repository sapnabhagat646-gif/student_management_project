# Student Management System

This is my FastAPI assignment project for managing student records. I used Python, FastAPI, SQLAlchemy and SQLite.

## Folder structure

```text
student_management_fastapi/
├── app/
│   ├── config.py
│   ├── database.py
│   ├── model.py
│   ├── schemas.py
│   └── routes/
│       ├── base.py
│       ├── create_students.py
│       ├── get_students.py
│       ├── update_students.py
│       └── delete_students.py
├── main.py
├── requirements.txt
└── .env
```

## How to run

Open this folder in VS Code and run these commands in the terminal:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

uvicorn main:app --reload
```

Open `http://127.0.0.1:8000/docs` to test the API.

## API endpoints

| Method | URL | Use |
|---|---|---|
| POST | `/students/` | Add a student |
| GET | `/students/` | Show students |
| GET | `/students/{student_id}` | Show one student |
| PUT | `/students/{student_id}` | Update a student |
| DELETE | `/students/{student_id}` | Delete a student |

The student table stores the student's name, date of birth, email, phone number, class and section. The ID is generated by the database.

## Example data

Use this JSON with the POST endpoint:

```json
{
  "student_name": "sapna kushwaha",
  "student_dob": "2005-11-02",
  "email": "aarav@example.com",
  "phone": "9876543210",

  "student_section": "A"

```

## What each file does

- `main.py`: starts the FastAPI application and connects the routes.
- `config.py`: reads application settings.
- `database.py`: creates the database connection and session.
- `model.py`: defines the students table.
- `schemas.py`: checks the request data.
- `create_students.py`: adds new students.
- `get_students.py`: lists students or finds one student.
- `update_students.py`: changes student details.
- `delete_students.py`: removes a student.
- `base.py`: includes the route files in the application.

The optional Ollama feature is not included because the main assignment only requires CRUD operations.
